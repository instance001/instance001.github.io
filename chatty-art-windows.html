Windows portable release

Install Chatty-Art for local media generation.

Chatty-Art is a local-first image, GIF, video, and audio generation dashboard for Windows. The portable release gives you the app shell and local workspace layout; you bring the models, runtime companion files, and hardware that fit your chosen generation lane.

Install steps

Download chatty-art-windows-portable-v0.4.zip, extract it to a normal folder such as Documents or the Desktop, then open the extracted folder and double-click Run Chatty Art.bat.

Chatty-Art creates its working folders beside the launcher on first run, including model, input, output, runtime, workflow, and bridge folders. This keeps the portable release inspectable and easy to move.

If Windows SmartScreen warns that the app is from an unknown publisher, that means the executable is not code-signed by a commercial certificate. Use the GitHub release, source repository, and checksum below to verify the package source before running it.

Models and runtimes

Chatty-Art does not include model weights. Put local GGUF models, realism model files, LoRAs, audio packages, and companion files into the folders documented in the repository README.

Expressive generation uses local GGUF models. Realism image, video, and audio paths may need extra local runtime projects or companion files such as stable-diffusion.cpp, VAE files, text encoders, audio model packages, or ffmpeg depending on the selected lane.
