Windows portable release

Install Chatty-EDU without accounts, ads, or cloud dependency.

Chatty-EDU is an offline-first Windows learning assistant for schools, teachers, students, parents, and self-directed learners. The portable release is distributed as a zip file: extract it, run the launcher, and keep its data beside the app.

Install steps

Download chatty-edu-windows-portable-v0.6.zip, extract it to a normal folder such as Documents or the Desktop, then open the extracted folder and double-click Run Chatty Edu.bat.

Chatty-EDU stores its writable folders beside the launcher on first run. That makes the portable release easier to inspect, move, back up, and deploy on school-managed machines.

If Windows SmartScreen warns that the app is from an unknown publisher, that means the executable is not code-signed by a commercial certificate. Use the GitHub release, source repository, and checksum below to verify the package source before running it.

Models

Chatty-EDU does not include model weights. Schools, districts, parents, or users choose their own approved GGUF models and place them in the app's models/ folder. If no model is present, Chatty-EDU shows setup guidance rather than silently calling a cloud service.

The core design is local-first: local when privacy, control, classroom trust, or offline use matters. Optional local networking is EDU-to-EDU over LAN only and activates only when the user enables it.
