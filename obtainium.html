Obtainium installs

Use GitHub Releases as an Android update path.

Obtainium can install Android APKs from GitHub Releases and check those release pages for future updates. For FMI apps, this gives advanced Android users a non-Play install route while keeping the public source repository and the downloadable APK in the same place.

Step-by-step

Install Obtainium from its official project page or another source you trust. Open Obtainium, choose to add an app, paste one of the FMI GitHub repository URLs below, and let Obtainium detect the latest APK from the repository's Releases page.

When Android asks for permission to install apps from Obtainium, allow it only if you are comfortable using this direct APK route. You can remove that permission later in Android settings.

What to expect

Obtainium is for users who are already comfortable installing APKs outside Google Play. It does not turn FMI into an app store; it simply watches the release pages we already publish. If that feels fiddly, Google Play is the right path.

FMI APK releases are provided to improve access, transparency, and user choice. They do not change the app privacy stance: Chatty-Pet remains local-first with device-local progress, and Chatty-mini sends data to a cloud provider only when the user explicitly configures and selects that provider.
