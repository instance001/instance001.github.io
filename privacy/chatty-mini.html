Chatty-mini Privacy Policy

Effective date: July 15, 2026

Chatty-mini is published by Fractal Media Infrastructure (FMI). It is a local-first Android chat application for user-supplied GGUF models, with optional user-configured cloud model connections. It does not require an account and is not built around advertising, analytics, tracking, or the sale of user data.

Summary

  • Local GGUF conversations and app files remain on the device.
  • Cloud use is optional and occurs only when the user selects a configured cloud model.
  • Cloud prompts and relevant Chatty-mini context are sent directly to the selected provider or custom endpoint.
  • FMI does not operate an intermediary inference server for Chatty-mini.
  • The app has no FMI account system, ads, in-app purchases, or analytics SDK.

Data stored locally

Chatty-mini stores data needed for app operation in private app storage. Depending on the features used, this can include imported GGUF model files, chat history, saved character prompts, summaries and context, sandbox files, session or cold logs, model configuration, and app settings.

This information is not uploaded to FMI. Android normally prevents users and other apps from directly browsing the private app directory. Sandbox files are copied outside private storage only when the user explicitly exports a file through Android's document picker.

Optional cloud model connections

Users may configure OpenAI, Anthropic, Google Gemini, xAI, DeepSeek, or a custom OpenAI-compatible endpoint. No cloud model is required, and Chatty-mini does not automatically fall back from local inference to a cloud service.

When a cloud model is selected and the user sends a message, Chatty-mini sends the prompt and the relevant conversation, character, summary, or sandbox context needed for that request directly to the selected endpoint. The selected provider receives and processes that content under its own terms and privacy policy. Network services may also receive ordinary connection information such as the user's IP address.

Users should avoid sending sensitive information to a cloud provider unless they understand and accept that provider's practices. A custom endpoint is controlled by its operator, not FMI.

API keys and security

Cloud API keys are stored locally using encryption backed by Android Keystore. Requests are sent over HTTPS when the configured endpoint uses HTTPS. API keys are supplied to the selected provider to authenticate requests and are not sent to FMI.

Users who configure a custom endpoint are responsible for choosing a trusted HTTPS service. FMI cannot control the security, retention, or processing practices of third-party providers or user-specified endpoints.

Data collection, analytics, and sharing

FMI does not collect Chatty-mini prompts, chats, local files, API keys, model files, diagnostics, advertising identifiers, or usage analytics through the app. FMI does not sell user data or share it for advertising or profiling.

The only external disclosure initiated by normal app use is the user-directed transfer to a selected cloud provider or custom endpoint described above, plus files the user intentionally exports through Android's system interface.

Permissions and system interfaces

Chatty-mini declares internet access so optional cloud requests can work. Local model import and sandbox export use Android's system document picker, which lets the user choose specific files or destinations without granting the app broad access to shared storage.

Retention and deletion

FMI does not retain user content on an FMI server because Chatty-mini does not send that content to FMI. Local data remains on the device until the user deletes it in the app, clears Chatty-mini's app data through Android settings, or uninstalls the app. Uninstalling or clearing app data generally removes private app files, including imported models and unexported sandbox files.

Data sent to a cloud provider is subject to that provider's retention and deletion practices. Users must contact or use the controls supplied by that provider for requests concerning provider-held data. Chatty-mini does not create FMI user accounts, so there is no FMI app account to delete.

Children

Chatty-mini is a general-purpose model interface and is not specifically directed to children. Parents and guardians should review the app, any imported model, and any configured cloud provider before allowing a child to use it.

Changes to this policy

If Chatty-mini changes in a way that affects privacy expectations, this policy will be updated before or alongside the relevant release. The effective date at the top of this page identifies the current version.
