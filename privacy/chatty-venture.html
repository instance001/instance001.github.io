Chatty-Venture Privacy Policy

Effective date: September 14, 2026

Chatty-Venture is a local-first Android text-adventure app published by Fractal Media Infrastructure (FMI). It has no user account system, advertising, analytics SDK, or sale of user data.

Summary

  • Stories, local models, prompts, and settings remain in private app storage unless you deliberately choose a cloud provider or contact FMI.
  • Cloud narration is optional and runs only after you select and configure a provider.
  • FMI does not operate an intermediary inference server for Chatty-Venture.
  • The Message developer feature sends only the subject and note you intentionally enter.

Data stored on your device

Chatty-Venture stores adventure saves, narration history, selected or imported GGUF models, prompt settings, API-key configuration, and app settings in Android private app storage. The app offers controls to remove this data. Clearing app data or uninstalling normally removes private app files created by the app.

Optional cloud narration

If you explicitly configure and select a cloud provider, the narration request and relevant story context are sent directly to that provider or custom endpoint. The provider processes that material under its own terms and privacy policy and may receive ordinary connection information such as your IP address.

Cloud API keys are stored locally using Android Keystore-backed protection. They are supplied to the selected provider to authenticate the request and are not sent to FMI.

Message developer

Message developer is voluntary. Sending a message transfers only the subject and note entered in that form, together with a random message ID, timestamp, and app version, to FMI for support. It does not automatically include adventures, narration, prompts, API keys, device identifiers, or diagnostics. Opening the form sends nothing.

Data collection and sharing

FMI does not collect ordinary gameplay data, prompts, local models, API keys, advertising identifiers, or analytics. FMI does not sell data or share it for advertising. The only external transfers are the optional cloud request and a developer message that you explicitly send.

Retention and deletion

Local data remains until you remove it in the app, clear app data, or uninstall. Data sent to a cloud provider follows that provider's retention practices. To request deletion of a submitted developer message, contact FMI and include the message ID when available.

Changes and contact

This policy will be updated with releases that materially change privacy expectations. For privacy questions, contact fractalmediainfrastructure@gmail.com.
