Selected active lanes

A curated view of the current ecosystem.

This page highlights six representative active lanes rather than attempting to reproduce the full repository index. For the complete GitHub corpus, use the instance001 repository surfaces directly.

Full body of work

Local-first AI tools

Projects focused on offline-capable assistants, local media generation, local LLM build and training workflows, quantization, and practical software for everyday use without forced cloud dependency.

Examples: Chatty-Cog, Chatty-Pet, Chatty-Art, Chatty-Lora, Nanochat LLM Tweaker (local LLM build suite), Chatty-Factory, Chatty-Quest

Education and learning tools

Projects focused on accessible, local-first educational software for students, teachers, parents, and self-directed learners who need practical tools without accounts, tracking, or cloud dependence.

Examples: Chatty-EDU, Chatty-EDU User

Interaction and behavior frameworks

Reusable guidance for higher-quality human-AI collaboration, session recovery, drift reduction, and explicit operating constraints across tools and providers.

Examples: AI Teaming Framework, Model Behaviour Toolkit

Memory and architecture research

Research into semantic sorting, compact memory, semantic compression, reducer-governed persistence, model suitability fingerprinting, and the technical structures needed for more legible local AI systems. This lane includes the small reusable RD Engine state core, the operator-facing LLM Semantic Dataset Sorter workbench for fixed-budget semantic partitioning, the contained Cognition Mesh Test Chamber evaluation lane, and later downstream work such as LLM-Defined Persistent Memory, Semantic Signal Alphabet, Janet-School, and parts of Chatty-Quest.

Examples: RD Engine, LLM Semantic Dataset Sorter, Cognition Mesh Test Chamber, LLM-Defined Persistent Memory, Semantic Signal Alphabet, Janet-School

Governance and safety analysis

Work examining alignment incentives, epistemic governance, safety theater, and the practical consequences of suppressing user or operator agency.

Examples: Governance by Design Report, Safety Theatre

Foundational theory and companion research

Long-cycle conceptual work on cognition, entropy-handling, model behavior, and associated theoretical scaffolds intended for public scrutiny rather than institutional gatekeeping.

Examples: Relational Curriculum Geometry, Entropy Folding hypothesis, cross-domain signal atlas, foundational frameworks
