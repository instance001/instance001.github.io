Public orientation and releases

Public-facing surfaces for understanding FMI, finding support, checking app-store releases, and choosing a path into the broader repository ecosystem.

Local-first AI tools

Projects focused on offline-capable assistants, small-phone Android chat, local media generation, local LLM build and training workflows, and practical software for everyday use. The stance is local first, cloud optional: cloud when it helps, local when it fits.

Examples: Chatty-Cog, Chatty-mini, Chatty-Pet, Chatty-Art, Chatty-Art Windows install, Chatty-Lora, Nanochat LLM Tweaker, Chatty-Factory, Chatty-Quest

Education and learning tools

Projects focused on accessible, local-first educational software for students, teachers, parents, and self-directed learners who need practical tools without accounts or tracking. Local-first here means user control first, with hosted services kept as deliberate choices rather than hidden dependencies.

Examples: Chatty-EDU, Chatty-EDU Windows install, Chatty-EDU User

Interaction and behavior frameworks

Reusable guidance for higher-quality human-AI collaboration, session recovery, drift reduction, and explicit operating constraints across local models, hosted models, tools, and providers.

Examples: AI Teaming Framework, Model Behaviour Toolkit

Host memory and architecture

Research into host-side memory, relational reasoning, earned abstraction, failure-aware routing, reducer-governed persistence, semantic sorting, model suitability fingerprinting, and compact continuity for legible local AI systems.

Examples: Project Leviathan, EF Engine, RD Engine, LLM Semantic Dataset Sorter, Cognition Mesh Test Chamber, LLM-Defined Persistent Memory, Semantic Signal Alphabet

Governance and safety analysis

Work examining alignment incentives, epistemic governance, safety theater, and the practical consequences of suppressing user or operator agency.

Examples: Governance by Design Report, Safety Theatre

Examples: AI Fair-Go page, Australian AI Fair-Go repo, Chatty-EDU, Chatty-Cog
